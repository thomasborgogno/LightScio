# Prompt for the LightSciò app icon

Use it with any image generator. English works best with most of them.

```
App icon for "LightSciò", a desktop app that creates concert light shows from a band's music tracks.
A single stylised stage moving-head spotlight seen from the front at a slight angle, mounted at the top,
casting three bold light beams downward that fan out: warm amber, hot magenta and electric cyan,
crossing over a dark deep-navy background. At the bottom, where the beams land, a short glowing
audio waveform line (like a sound wave) in white-gold, as if the light is "playing" the music.
Subtle haze/glow around the beams, crisp clean edges.
Style: modern flat-ish vector icon with soft gradients and a gentle inner glow, like a macOS / Windows 11
app icon; rounded-square tile (squircle) with a very dark navy-to-black vertical gradient; centered
composition with generous padding; high contrast so it stays readable at 16×16 and 32×32 px;
no text, no letters, no logos, no people, no photorealism.
Square 1024×1024, transparent background outside the rounded tile.
```

Tips:

- If the result is too busy, add: `minimal, only 2 beams, thicker shapes`.
- For the small Windows icon (16–32 px), ask for a variant without the waveform: `same icon, beams only, simplified for very small sizes`.
- When you have the final PNG (1024×1024), put it in `docs/icon.png`. It can then be added to the window, the Windows installer (`.ico`) and the macOS app (`.icns`).
